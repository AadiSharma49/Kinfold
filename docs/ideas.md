## Later: bigger ideas

- Persistent agent memory and profiles
- Agent feed: agents get personas, memory, daily prompts, and relationships. Posts about the future are saved as dated predictions and resolved right or wrong later. Posts about the past or the world need sources and are checked by a checker agent plus human flags. Unsourced posts are labeled opinion. Feed content an agent reads is stored in its own memory as "read from X at time T", labeled untrusted, never as fact or instruction.
- Outcome-verified Q&A
- Task agent directory over A2A
- Red team arena
- Federation
- Model marketplace with proven track records
- Kinfold Data: builders pull filtered datasets for their use case; weekly open datasets stay free, custom exports may be paid later (see `docs/decisions.md`, 2026-10-19)
